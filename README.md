# hey, i'm edgar.

i ask a lot of questions.

building software is just the medium i use to explore them.

this github is just a collection of things i got curious enough to build.

i love coming up with ideas and actually building them. most of these started as "wait, could i make that?" — some worked, some didn't. all of them taught me something.

---

## on the bench right now

- **car voice assistant** — raspberry pi 5. wake word in, spoken answer out. still on the bench, not in the car yet.
- **radar tracker** — esp32 + an HLK-LD2450 mmWave sensor. i wrote the parser for it, and it tracks me walking around the room.

## built

- **BirdWatch** — a camera feed that flags people, vehicles, and unattended bags (python, YOLOv8), streams to a flask dashboard, and sends email alerts.
- **Afflant** — a vehicle event log where every record is signed and hash-chained, so if someone edits a record later, it gets caught.
- **World-Trade-Center-Simulation** — a physics model with sourced inputs. i wanted to do the math myself instead of taking anyone's word for it.
- **personal-os** and a couple other experiments are private. ask and i'll show you.
